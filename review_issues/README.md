## 🚀 How to Create Issues on GitHub

### Method 1: Using GitHub CLI (Recommended)

If you have the GitHub CLI installed and authenticated:

```bash
chmod +x ../create_github_issues.sh
../create_github_issues.sh
```

### Method 2: Using Python Script with GitHub Token

1. Create a GitHub Personal Access Token:
   - Go to https://github.com/settings/tokens
   - Click "Generate new token (classic)"
   - Select scope: `repo`
   - Copy the generated token

2. Run the upload script:

```bash
# Option A: Using environment variable
export GITHUB_TOKEN=your_token_here
python3 ../upload_issues_to_github.py

# Option B: Using command line argument
python3 ../upload_issues_to_github.py --token YOUR_TOKEN

# Option C: For a specific repository
python3 ../upload_issues_to_github.py --token YOUR_TOKEN --repo phismith91/luxorliving
```

### Method 3: Manual Creation

1. Review each `.md` file in this directory
2. For each file:
   - Copy the title (first line without `#`)
   - Copy the body (content after the `---` separator)
   - Note the labels (listed after `**Labels:**`)
3. Create a new issue on GitHub:
   - Go to https://github.com/phismith91/luxorliving/issues/new
   - Paste title and body
   - Add the labels manually
   - Submit the issue
